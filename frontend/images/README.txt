Car photos used by the site (transparent PNG cut-outs work best, ~1000-1400px wide):

bmw.png  rr.png  scorpio.png  fortuner.png

To add a car: add an entry to CARS in src/app.js with id = the file name (without .png), put the PNG here, then run: node build.js
Optional: hero.jpg = a wide showroom photo to use as the full-bleed hero background.
Use your own photos or manufacturer press images you have permission for.
